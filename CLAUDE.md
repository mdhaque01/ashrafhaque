# Site rules
- Academic personal website for a public administration PhD candidate on the job market
- Built with Quarto, output to docs/
- Audience: search committee members skimming for 30 seconds
- Voice: direct, short sentences, no em dashes, no semicolons
- No marketing language, no narrative hooks, no "passionate about"
- Palette: #FFFFFF background, #1A1A1A text, #1F3864 accent for links only
- Typography: one serif for headings, one sans for body, nothing else
- NEVER write a publication, title, journal, year, or coauthor that does not
  appear in _source/. If unsure, write TODO and ask me.
